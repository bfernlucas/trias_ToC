# Trias Brasil — Ecossistema da Filantropia

Repositório de trabalho para a construção do mapeamento do ecossistema da
filantropia no Brasil e o desenho da estratégia de atuação da Trias no país
para os próximos anos, conforme o draft do programa.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `data/` | Datasets, planilhas, indicadores quantitativos do setor |
| `docs-referencia/` | Documentos externos de referência (relatórios, estudos, marco regulatório) |
| `pesquisa/` | Notas de pesquisa, entrevistas, sínteses analíticas |
| `mapeamento/` | Mapeamento de atores do ecossistema (financiadores, intermediários, redes, ONGs) |
| `estrategia/` | Draft do programa Trias, hipóteses estratégicas, teoria da mudança |
| `outputs/` | Entregáveis: apresentações, memos, documentos finais |

## Convenções

- Idioma padrão: português. Termos técnicos em inglês quando consagrados.
- Nomes de arquivo: `kebab-case`, sem acentos, com data quando relevante (`YYYY-MM-DD-titulo.md`).
- Fontes externas em `docs-referencia/` devem ter um arquivo `.md` companheiro com citação completa e link.
