# outputs/

Entregáveis finais e materiais de comunicação derivados do trabalho.

## O que vai aqui

- Apresentações para a Trias (board, equipe global, parceiros).
- Memos executivos e sumários.
- Relatório final de mapeamento do ecossistema.
- Documento de estratégia consolidado.
- Materiais de divulgação eventualmente compartilhados com o ecossistema.

## Convenções

- Nomear com data e versão: `2026-MM-DD-titulo-vN.pdf`.
- Manter o arquivo-fonte (`.md`, `.pptx`, `.key`, `.docx`) junto do exportado
  (`.pdf`) quando aplicável.
- `outputs/` é o que sai para fora — revisar antes de versionar.
