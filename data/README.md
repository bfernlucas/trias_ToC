# data/

Datasets e indicadores quantitativos sobre o ecossistema da filantropia no Brasil.

## O que vai aqui

- Planilhas e CSVs com dados de doação, investimento social privado, número de
  organizações, recursos mobilizados.
- Indicadores macro do setor (BISC, GIFE Censo, IDIS, Doação Brasil, etc.).
- Dados públicos relevantes (Receita Federal — OSCs, MROSC, IBGE).

## Convenções

- Cada dataset acompanhado de um `.md` com: fonte, ano de referência, metodologia,
  data de coleta, link original.
- Dados brutos em `raw/`, dados tratados em `processed/` (criar quando necessário).
- Não versionar arquivos > 50 MB; usar referência/link.
