# docs-referencia/

Documentos externos de referência usados como base para o trabalho.

## O que vai aqui

- Relatórios de instituições do setor (GIFE, IDIS, ABCR, Movimento Bem Maior,
  Comitê pela Filantropia, Filantropia Estratégica BR).
- Estudos acadêmicos e papers sobre filantropia, sociedade civil e investimento
  social no Brasil.
- Marco regulatório: MROSC (Lei 13.019/2014), Lei das OSCIPs, legislação de
  endowments (Lei 13.800/2019), tributação de doações.
- Benchmarks internacionais relevantes (modelos de atuação de fundações
  europeias na América Latina).

## Convenções

- PDFs e documentos originais na pasta.
- Para cada documento, um `.md` companheiro com: título, autor/instituição, ano,
  link, resumo de 3-5 linhas, relevância para o projeto.
- Organizar por tema em subpastas quando o volume justificar
  (ex.: `marco-regulatorio/`, `dados-setor/`, `internacional/`).
